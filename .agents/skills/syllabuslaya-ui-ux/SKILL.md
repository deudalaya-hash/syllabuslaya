# Syllabusलय UI and UX

## Product principles

- Preserve the existing brand, educational information, sections, and user-facing features unless the user explicitly requests a change.
- Keep the homepage search-first, clear, and compact. Do not add duplicate search bars or unnecessary dashboard/card layers.
- Make the Pre-School–PhD structure discoverable without hiding essential search access. Expandable controls must have clear labels and predictable open/close behavior.
- Keep semester/year selection easy to reach and show the active choice clearly.

## Design workflow

1. Inspect existing markup, styles, breakpoints, colors, and user flows before proposing a visual change.
2. Make the smallest change that satisfies the request and fits the existing brand.
3. Check narrow screens, long programme/subject names, touch target size, keyboard order, focus visibility, contrast, and reduced-motion behavior.
4. Preserve content and interactions while adjusting layout; never silently remove a pathway or control.

## Accessibility and validation

- Prefer native button, select, details, summary, label, and form semantics.
- Provide accessible names and state such as aria-expanded and aria-pressed where needed; do not use color alone to convey selection.
- Ensure menus and suggestions remain within the viewport and are usable by keyboard and touch.
- Use the available accessibility and browser-testing skills when the environment supports them. Report unavailable visual checks honestly.
