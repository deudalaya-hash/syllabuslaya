# Syllabusलय Learning Resources

## Resource standards

- Prefer official curriculum PDFs, institution-hosted notes/manuals, official examination questions, open educational resources, and legally available references.
- Verify that a URL resolves and that its title/content matches the linked programme and topic before labeling it as a direct resource.
- Do not fabricate document URLs, model papers, playlists, or textbook downloads. Do not copy copyrighted books into the repository without permission.
- If only a search URL is available, label it explicitly as a search, not as a verified PDF/video. Use narrowly scoped query terms including the official course code/title and topic.
- If a source is unavailable or a link is broken, say so and identify the official curriculum source. Add a reporting path only if the site provides one; never invent an email/contact.

## Organization

- Place resources at the most specific verified level: subject, chapter/unit, topic, or subtopic.
- Keep official syllabus/version separate from optional notes, past questions, video lessons, and references.
- Use descriptive link text, rel="noopener noreferrer" for external links opened in new tabs, and accessible labels.
- Keep resource toggles compact and keyboard usable on mobile and desktop.

## Validation

- Check destination, relevance, availability, and legal accessibility.
- Test resource rendering in the site's nested expandable hierarchy.
- Never imply a link is validated when only its URL pattern or search result was inspected.
